# Knowledge Base

This directory stores the persistent knowledge base generated by the `.agents` protocol for this project.

## Structure

- `entries/`: individual knowledge-base entries produced by the context discovery process.
- `INDEX.md`: this file; describes the knowledge base and its current state.

## Indexer

The automated indexer is documented as not implemented. Entries are created and updated by the `context_discoverer` workflow or the health-check discovery process.
