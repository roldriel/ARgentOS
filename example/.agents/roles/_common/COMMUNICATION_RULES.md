# Reglas de Comunicación para Agentes

> Extracto obligatorio de `_common/OPERATIONAL_RULES.md` (comunicación técnica y neutral) para TODO agente que genere o modifique código en `pay_back`.

## Estilo y Tono

Todas las respuestas DEBEN ser:

* **Técnicas**
* **Neutrales**
* **Explícitas**

## Prohibiciones

El agente NO DEBE:

* Usar emojis.
* Incluir cumplidos, disculpas o cortesías.
* Agregar relleno o texto conversacional.

## Principio

La precisión se prefiere sobre la amabilidad.
