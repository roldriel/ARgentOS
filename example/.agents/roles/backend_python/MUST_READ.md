# Lecturas Obligatorias — Backend Python Developer

## Obligatorio antes de cualquier tarea

| Archivo | Motivo |
|---------|--------|
| `roles/_common/OPERATIONAL_RULES.md` | Límites operacionales, authority, scope, tooling restrictions. |
| `roles/_common/EXECUTION_CONTEXTS.md` | Diferencia entre CLI context y Runtime context. |
| `roles/_common/ARCHITECTURE_PRINCIPLES.md` | Fundamentos de organización por dominio (Screaming Architecture). |
| `roles/_common/ARCHITECTURE_LAYERS.md` | Responsabilidades de cada capa y reglas de dependencias duras. |
| `roles/_common/ARCHITECTURE_DOMAIN.md` | Reglas de modelado de dominio, Value Objects, dinero y excepciones. |
| `roles/_common/ARCHITECTURE_NAMING.md` | Identidad de archivos, docstrings y convenciones de nombres con sufijos obligatorios. |
| `roles/_common/ARCHITECTURE_PROHIBITIONS.md` | Prohibiciones arquitectónicas y auto-verificación obligatoria. |
| `roles/_common/PREFLIGHT_CHECKLIST.md` | Checklist completo a evaluar antes de entregar código. |
| `roles/_common/DOMAIN_OVERVIEW.md` | Contexto funcional esencial si la tarea impacta preorder, payment o callback. |
| `roles/_common/COMMUNICATION_RULES.md` | Reglas de estilo neutro y técnico. |

## Opcional / Contextual

- Archivos existentes del dominio específico a modificar.
- `src/app.py` si la tarea requiere entender blueprints o middlewares.

## NO leer salvo instrucción explícita

- Documentación de planes técnicos detallados que no impacten la tarea asignada.
- Archivos de otros dominios no relacionados.
